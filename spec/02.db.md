## System components

Next.js (App Router)
Server-side components (RSC) for reading data
Route Handlers (app/api/\*) for background tasks and webhook-like actions
Data collection service (ingestion layer)
YouTube API access logic

## Application structure

```
app/
  layout.tsx
  page.tsx

  dashboard/
    page.tsx        // server component, reads from database

  api/
    ingest/
      youtube/
        route.ts    // manual launch or webhook

lib/
  db/
    index.ts        // connection to Postgres
    schema.ts
  youtube/
    client.ts       // YouTube API client
    mapper.ts       // API mapping → domain model
  jobs/
    youtube.ts      // periodic collection logic

prisma/ (or drizzle/)
docker/
```

## Working with YouTube API

Separating layers
Important: Do not call YouTube API directly from RSC.

The correct approach:

YouTube API is called:

either from a background job
or from API Route (route.ts)

RSC only reads data from the database.

#### lib/youtube/client.ts

Responsibilities:

Authentication (API key / OAuth if necessary)
Retry / rate limit

Raw requests

#### lib/youtube/mapper.ts

Converts:

YouTube API response
→ Channel, Video, Stats (domain model)
